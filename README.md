# mockd

Releases of the Mockd command line app. The source lives elsewhere; this repository only
carries the finished files.

## Install

macOS and Linux:

```sh
curl -fsSL https://mock-d.com/install | sh
```

Windows (PowerShell):

```powershell
irm https://mock-d.com/install.ps1 | iex
```

Then start it with `mockd`.
